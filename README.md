# Re-Spawn

Next.js starter using TypeScript, App Router, Tailwind CSS, and ESLint.

## Getting started

Requires Node.js 20.9 or newer and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Edit `app/page.tsx` to update the home page and `app/layout.tsx` to update the shared layout.

## Commands

- `npm run dev` — start the development server.
- `npm run build` — create a production build.
- `npm start` — serve the production build.
- `npm run lint` — run ESLint.

Created following the [Next.js installation guide](https://nextjs.org/docs/app/getting-started/installation).
